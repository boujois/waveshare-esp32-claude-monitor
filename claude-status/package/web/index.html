Claude Monitor installer

Set up the round desk display that lights up when Claude needs you.

On a Mac? One line does it all

Plug the display into your Mac, open Terminal (in Applications → Utilities), paste this line and press Return:

/bin/bash -c "$(curl -fsSL https://boujois.github.io/waveshare-esp32-claude-monitor/install.sh)"

It puts the software on the display, tells you when to connect it to your Wi-Fi, and sets up your Mac, with no browser needed. Or follow the steps below in Chrome or Edge.

1

Plug in the display

Connect the round display to this computer with a USB-C cable. It must be a cable that carries data. Many charging-only cables don't.

Which display is it?

2

Install the firmware

Click the button, choose the display from the list (it usually shows as USB Single Serial or usbmodem…), and click Install. It takes about a minute.

This browser can't talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a computer.

The installer needs a secure (https) page. Open it from the link in the README.

Updating an existing display keeps its Wi-Fi settings. Only choose "erase" if you want to start completely fresh.

3

Connect it to your Wi-Fi

The display now shows a Wi-Fi setup screen with a QR code. On your phone, scan it or join the Wi-Fi network Claude-Monitor-Setup. A page opens where you pick your home Wi-Fi and enter its password.

The display only works with 2.4 GHz Wi-Fi. If the page doesn't open by itself, go to 192.168.4.1 in your phone's browser.

4

Set up your Mac

Open Terminal (in Applications → Utilities), paste this line and press Return. It's the same line as at the top: it sees the display is set up and goes straight to your Mac.

/bin/bash -c "$(curl -fsSL https://boujois.github.io/waveshare-esp32-claude-monitor/install.sh)"

It installs the Mac helper and menu bar app from the latest release and asks a few questions. Then click the Claude Monitor icon in the menu bar, a small circle inside a circle, to connect your plan usage and set up night mode.

The display switches from "Waiting for Mac" to your Claude status within a few seconds.

Rather not use Terminal? Download Claude-Monitor-Mac.zip from the latest release, open it and double-click Install.command. macOS stops it the first time: click Done, then open System Settings → Privacy & Security and click Open Anyway.

Need to change Wi-Fi later? Unplug the display and plug it back in 3 times in a row, each within 10 seconds of the last, to reopen Wi-Fi setup.
